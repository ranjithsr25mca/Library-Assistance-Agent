OpenRouter LLM Recommendation Architecture

1. Real-Time LLM Reasoning

Recommendations, scores (0-100), and explanations are computed dynamically by the LLM without hardcoded scoring tables.

2. Secure API Key Storage (.env)

Your OpenRouter API key is stored securely in .env on the server and never exposed to the client browser.

3. Configurable Model

Swap models anytime in .env (e.g. openai/gpt-4o-mini, meta-llama/llama-3.3-70b-instruct, or google/gemini-2.0-flash-001).
